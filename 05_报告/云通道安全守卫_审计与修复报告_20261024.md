# 云通道安全守卫 · 审计与修复报告（第 26 轮）

**时间**：2026-10-24
**触发**：10-24 凌晨 `deploy/static/index.html` 新增「WorkBuddy 云服务 · AI 风险摘要」（后端未配 DeepSeek key 时，前端浏览器直连云 LLM 补齐摘要）。本轮对该新改动做专项安全审计 + 全量门禁回归。
**范围**：`deploy/` 与 `01_交付包/本地运行包/` 两副本的前端云通道代码、`server.py` 写守卫覆盖面、出网点普查。

## 一、问题清单（按严重程度）

### P0-1 涉密通道评分明细被发往第三方云 LLM（已修复）

| 项 | 内容 |
|---|---|
| **位置** | `static/index.html::showResult`（AI 摘要分支） |
| **根因** | `showResult(data, channel)` 持有 `channel` 参数，但 AI 摘要分支未消费它：涉密上传（`channel === "classified"`）的 `merged.ai_analysis` 恒为空（涉密通道设计上不调任何模型）→ `aiIsPlaceholder` 恒真 → 渲染「WorkBuddy 云服务」卡片并调用 `fhFillCloudSummary` |
| **后果** | **涉密文件的评分明细（供应商名、六维分数、命中规则、红线）从浏览器明文发往 `fenghuo-outsourcing-risk.app.workbuddy.host`**，直接击穿「涉密不调用任何模型、不出网」的核心安全承诺——该承诺写在 README 安全边界表、方案书与页面上（"本地解析 · 不出内网"徽标）。演示中评委打开网络面板即可取证；答辩被追问即是致命伤 |
| **修法** | AI 摘要分支前置 `isClassified = channel === "classified"`：① 涉密通道渲染固定说明「涉密通道仅做本机规则评分，不调用任何模型（含云端）」，不产生 `data-fh-ai-body` 元素；② 云调用入口双保险 `if (aiIsPlaceholder && !isClassified)` |
| **验证** | E2E `ui_verify_cloud_guard.js` A1–A4：涉密结果页显示固定说明、无云占位、**云 SDK 收到的提示词数 = 0**、无真实外部请求 |

### P1-2 公开通道云提示词携带公司名，与后端脱敏口径不一致（已修复）

| 项 | 内容 |
|---|---|
| **位置** | `static/index.html::fhBuildPrompt` |
| **根因** | 后端 DeepSeek 通道上云前先 `_mask_text`（公司名→占位符），而新增的前端云提示词首行直接写 `供应商：<公司全称>`，绕开了同一安全口径 |
| **修法** | 提示词首行固定为「目标供应商（名称已按脱敏口径隐去）」；维度分数/规则名/红线等事实项保留（非敏感） |
| **验证** | E2E B2/B3 + D2：提示词不含公司名、含维度事实；直接调用 `fhBuildPrompt` 复核 |

### P2-3 两副本漂移：云通道改动只落 `deploy/`，交付包滞后（已修复）

10-24 的云通道改动仅存在于 `deploy/static/index.html`，交付包（唯一交付口径）与 `app/` 均为旧版。修复后已将 `deploy/static/index.html` 同步至 `01_交付包/本地运行包/static/index.html` 与 `app/static/index.html`，三副本 `diff` 一致（`app/` 仅求一致性，非交付口径）。

## 二、广谱复查结论（无新问题）

| 检查项 | 结论 |
|---|---|
| 前端出网点普查 | 全页仅 4 类外联：jsdelivr SDK 脚本加载、WorkBuddy endpoint/relay（仅 `fhFillCloudSummary` 一个调用点，已设通道闸）、企查查官网链接（用户点击）、同源 API。`fetch/XMLHttpRequest/sendBeacon` 无其他外部目标 |

| `_write_guard` 中间件 | 本机免密 + 跨主机 fail-closed 令牌 + `FENGHUO_READONLY_WRITES` 只读总闸，逻辑无误 |
| 首页改版层（fh-router） | hash 路由独占 `location.hash`、只调用真源 `switchPage/switchTab`，与云通道无交集 |
| `root()` 令牌注入 | 按 `FENGHUO_FRONTEND_TOKEN` 意图注入、JSON 编码防注入，无误 |
